# ML/NLP Academy — Junior → Strong Junior

Локальное учебное веб-приложение для системного изучения ML Engineering, NLP и LLM.

## Что добавлено в улучшенной версии

- **240 flashcards** по всем roadmap-блокам.
- **240 вопросов** для adaptive assessment: single-choice и text-answer.
- **30 практических задач** по Python, SQL, NumPy, алгоритмам, ML, NLP и LLM.
- Уровни обучения: **Junior** и **Strong Junior**.
- **Spaced repetition** для карточек: Again / Hard / Good / Easy, streak, interval, ease и due date.
- **Skill engine** по каждой теме: mastery 0–100%, attempts, accuracy, streak и текущий уровень сложности.
- **Adaptive testing**: вопросы выбираются с учётом mastery, ошибок, текущей сложности и выбранного карьерного уровня.
- **Интерактивный Python runner** через Pyodide в браузере.
- **Интерактивный SQL runner** через SQLite WASM / SQL.js в браузере.
- Сохранение истории запусков coding-задач.
- Mock HR + technical interview без текстового поля ответа.
- Roadmap с прогрессом по темам.
- Dashboard со слабыми зонами и задачами на сегодня.
- JSON Export / Import всего прогресса.
- Миграция старого формата прогресса v1 → v2.

## Запуск

Требуется **Node.js 18+**, желательно актуальный LTS.

```bash
cd ml-nlp-academy
npm install
npm run dev
```

Vite покажет локальный адрес, обычно:

```text
http://localhost:5173
```

Production build:

```bash
npm run build
npm run preview
```

## Интерактивный Python / SQL

Приложение не отправляет пользовательский код на собственный сервер.

- Python выполняется в браузере через **Pyodide/WebAssembly**.
- SQL выполняется через **SQLite WASM / SQL.js**.

При первом запуске конкретного runtime браузеру нужно скачать runtime с CDN. После загрузки выполнение происходит локально в браузере.

Если требуется строго полностью офлайн-режим без CDN, Pyodide и SQL.js можно позже положить в `public/runtime/` и поменять URL загрузки в `src/lib/execution.ts`.

## Как работает spaced repetition

Для каждой карточки сохраняются:

- `seen` — количество повторений;
- `correct` — количество успешных воспроизведений;
- `streak` — серия успешных воспроизведений;
- `interval` — текущий интервал в днях;
- `ease` — коэффициент лёгкости;
- `due` — timestamp следующего повторения;
- `lastQuality` — последняя оценка.

Кнопки:

- **Again** — сбросить серию и повторить скоро;
- **Hard** — короткий интервал;
- **Good** — обычное увеличение интервала;
- **Easy** — ускоренное увеличение интервала.

Это упрощённая SM-2-подобная схема, специально сделанная прозрачной и полностью локальной.

## Как работает adaptive testing

Для каждой темы хранится `mastery` и текущий уровень сложности.

- правильный ответ увеличивает mastery;
- ошибка уменьшает mastery;
- серия правильных ответов может повысить уровень темы;
- ошибки на сложных вопросах сильнее влияют на skill state;
- следующий вопрос получает больший вес, если тема слабая или вопрос находится немного выше текущего уровня пользователя.

Тест ограничивает одну сессию восемью вопросами, но выбирает их из расширенного пула.

## Содержание roadmap

### ML Engineering
Python, NumPy, Pandas/EDA, математика, вероятность и статистика, ML fundamentals, preprocessing, classical models, metrics/validation, MLOps.

### Programming
SQL, алгоритмы и структуры данных, Git/Linux.

### NLP
Text preprocessing, TF-IDF, embeddings, Transformers, BERT/fine-tuning.

### NLP / LLM
LLM fundamentals, prompt engineering, RAG, fine-tuning/LoRA, LLM evaluation, agents/production.

## Важное ограничение

Python/SQL runner сейчас даёт реальное выполнение кода для интерактивных задач, но не является полноценной системой проверки произвольных пользовательских проектов. Для задач без автоматического тестового harness всё равно доступна ручная проверка по эталонному решению.

## Обновлённая механика карточек

В версии с обновлёнными карточками:
- все 240 существующих карточек сохранены, но ответы объединены в единый блок без секций «Как это запомнить» и «Для практики»;
- ежедневная сессия составляет 20 карточек и подбирается по истории ответов, смешивая новые и изученные карточки;
- после завершения сессии доступны повтор того же набора и переход к следующему набору новых понятий;
- доступны наборы по каждой теме с выбором количества карточек и общий рандомизированный набор;
- после сессии показываются время прохождения, процент запомнившегося материала и количество карточек, которые потребуют повторения в ближайшие два дня;
- прогресс новых сессий сохраняется в `localStorage` и экспортируется/импортируется вместе с остальным прогрессом;
- адаптивные тесты, интерактивные задачи и Mock interview не изменялись.
