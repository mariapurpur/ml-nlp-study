# ML/NLP Academy

Обновлённая версия академии с геймификацией. Приложение использует React, TypeScript, Vite и локальное хранение в браузере.

## Запуск

1. Установите Node.js LTS (рекомендуется Node.js 20 или 22).
2. Откройте терминал в папке с проектом.
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите dev-сервер:
   ```bash
   npm run dev
   ```
5. Откройте адрес, который Vite выведет в терминале (обычно `http://127.0.0.1:5173`).

Для production-сборки используйте `npm run build`, для локального просмотра собранной версии — `npm run preview`.

## Что добавлено

- RPG-прогрессия из 100 уровней с возрастающей стоимостью уровней и XP-полосой.
- Автоматическое начисление XP за изучение карточек, вопросы собеседования, успешные задачи, закрытие тем и результаты тестов.
- Пять ежедневных контрактов с прогрессом и бонусным XP.
- Серия занятий (streak), отображение ранга и XP в шапке.
- Коллекция достижений, включая серебряные и золотые статусы навыков по mastery.
- Контрольный экзамен из 10 усложнённых вопросов; проходной балл — 80%, результат сохраняется.
- Добавлено 50+ карточек, 12 тестовых вопросов, 12 практических задач и 12 вопросов mock interview по темам Python, data analysis, ML, SQL, NLP, Transformers, RAG, LLM evaluation и agents.
- Существующий адаптивный тест, spaced repetition, задачи, импорт/экспорт и локальное сохранение прогресса сохранены.

## Прогресс и резервная копия

Прогресс хранится в `localStorage` текущего браузера. Обновление расширяет существующий формат данных и сохраняет уже накопленные карточки, mastery, историю тестов, задачи и streak. Для переноса на другой браузер/компьютер используйте кнопки экспорта и импорта JSON в шапке приложения. Не очищайте данные сайта, если хотите сохранить прогресс.

Новые достижения и XP начисляются после соответствующих учебных действий. XP и ачивки — игровая надстройка и не влияют на правильность оценивания учебных ответов.
